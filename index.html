АОСР — форма с загрузкой графика работ

Облачное хранение GitHub

Подключите репозиторий один раз на каждом устройстве. Для записи используется отдельный Fine-grained token только с правом Contents: Read and write для выбранного репозитория.

Облако не подключено

Файл данных: data/state.json. Токен хранится только в sessionStorage текущей вкладки и не записывается в репозиторий. Не публикуйте и не пересылайте его. Для максимальной безопасности после работы нажмите «Отключить».

Из графика берутся наименования работ, объёмы, фактические даты начала и окончания и подбираются материалы.
Из сметы или КС-2 берутся наименования работ, единицы, объёмы и материалы. PDF не читается — сохраните документ в Excel.
